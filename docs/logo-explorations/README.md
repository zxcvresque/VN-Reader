# VN Reader logo explorations

Three original vector directions for Vidurneeti’s post reader. Open `index.html` to compare each in light and dark, at large and actual interface sizes. These are archived early proposals. The reader now uses the supplied VN light and dark logo artwork; these drafts are retained only as design history.

- **Type** — a custom lowercase `vn.` mark that keeps the existing brand familiar and feels like a concise editorial signature.
- **Open pages** — two connected pages frame `v` and `n`, linking long-form reading with a connected archive.
- **Fold** — an upright geometric `VN` monogram designed for a compact navigation tile or app icon.

Each SVG has a transparent background, a scalable view box, accessible title, and `currentColor` ink. Inline the SVG to inherit any theme’s foreground color. The comparison sheet has no external fonts, scripts, or dependencies.
